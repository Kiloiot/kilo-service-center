# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in KiloCenter, please report it responsibly. **Do not open a public GitHub issue.**

Email **info@kiloiot.de** and include `KiloCenter Community Edition` in the subject so the shared
mailbox can route the report to the responsible team.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact assessment
- Any suggested remediation (optional)

Do not include credentials, private keys, customer data, or other sensitive production data in the
initial message. The team will arrange an appropriate restricted exchange if additional sensitive
evidence is needed.

## Scope

This policy covers the KiloCenter Community Edition codebase at
[github.com/Kiloiot/kilo-service-center](https://github.com/Kiloiot/kilo-service-center).

For security concerns related to an enterprise edition or Kilo Cloud, use the same address and name
the affected product and environment in the subject.

This file does not create a response-time, remediation-time, support-period, or disclosure-credit
commitment. Those values are published only after they are approved for the affected product.
