# Onboarding

## Purpose
This branch covers first success on a local environment: base station connectivity, endpoint registration, and first message validation.

## Pages
1. [Connect a Base Station](01-connect-a-base-station.md)
2. [Register an Endpoint](02-register-an-endpoint.md)
3. [Verify the First Uplink](03-verify-first-uplink.md)
4. [Schedule and Verify the First Downlink](04-verify-first-downlink.md)

## Completion Criteria

You have completed onboarding when:

- At least one base station is connected and showing online in KC-Web
- At least one endpoint is registered with correct keys
- An uplink message has been received and is visible in KC-Web
- A downlink command has been queued and delivered (for bidirectional endpoints)
