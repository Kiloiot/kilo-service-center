# Next Steps

## Goal

Move from understanding the product to a running local installation.

## Recommended Sequence

1. [Getting Started](../02-GettingStarted/README.md) -- install and configure KiloCenter
2. [Onboarding](../03-Onboarding/README.md) -- connect a base station and register endpoints
3. [Integrations](../04-Integrations/README.md) -- set up gRPC and MQTT consumers
4. [Security](../05-Security/README.md) -- TLS certificates and access control
5. [Operations](../06-Operations/README.md) -- monitoring and troubleshooting

## Success Criteria

You have completed the initial setup when:

- KC-Core, KC-Gateway, and KC-Web are running
- At least one base station is connected
- At least one endpoint is registered
- One uplink message has been received end-to-end
